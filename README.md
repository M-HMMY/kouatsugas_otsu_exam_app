# 高圧ガス乙種 学習アプリ

**高圧ガス製造保安責任者試験の「乙種化学」「乙種機械」**の学習アプリです。
教本・確認問題・間隔反復・模試を 1 つにまとめてあります。

**まだ足場だけです。**教本も問題も入っていません。

## 試験の形

**2026 年 9 月 15 日に、[高圧ガス保安協会（KHK）](https://www.khk.or.jp/)の
令和 8 年度受験案内書で確認した内容です。**要項は改訂されるので、受験の前に公式サイトで
確かめてください。

- **乙種化学と乙種機械の 2 区分。**どちらか一方を受けます
- **3 科目とも択一式。**乙種に記述式はありません（甲種の学識は記述式です）
- **1 区分 50 問** … 法令 **20 問 / 60 分**、保安管理技術 **15 問 / 90 分**、学識 **15 問 / 120 分**
- **合格基準は、各科目とも満点の 60 パーセント程度。**合計点ではありません
- **受験資格はありません。**年齢・学歴・性別・経験等に関係なく誰でも受けられます
- **科目免除があります。**講習の検定に合格していれば保安管理技術と学識が、
  もう一方の区分の免状を持っていれば法令が免除されます
- 受験手数料は電子申請 11,100 円 / 書面申請 11,600 円
- **年 1 回。**11 月の日曜日に全国同日（令和 8 年度は 11 月 8 日）

### 乙種化学と乙種機械の違い

**法令 20 問は両区分で共通です。**違うのは残り 2 科目です。

| 科目 | 乙種化学 | 乙種機械 |
| --- | --- | --- |
| 保安管理技術 | **化学**に関する通常の保安管理の技術 | **機械**に関する通常の保安管理の技術 |
| 学識 | 通常の**応用化学** | 通常の**機械工学** |

このアプリは**両方を収録**し、模試は区分を選んでから作ります。

| 合格基準 | 科目ごとに 60 % **以上** | 科目ごとに 60 % **程度** |

## 動かす

```
npm install
npm run dev      # 開発サーバ
npm run check    # データの整合性 + 実際に描いてみる検査
npx tsc --noEmit
npm run build
```

デスクトップから起動するショートカットを作る場合：

```
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\make_shortcut.ps1
```

## 方針

- **ランタイム依存は React だけ。**ルータ・Markdown・図はすべて自前
- **外部通信をしない。**学習記録は localStorage のみ。サーバもアカウントもない
- **オフラインで動く**（PWA）
- **合否は「この模試の結果が 6 割に届いたか」までしか出さない。**
  合格基準が「60 パーセント**程度**」で言い切られていないので、合否は判定しない
- **公開問題を原文のまま収録しない。**KHK のサイトに明示の転載禁止文は見当たりませんが、
  著作権表示がある以上、許諾が明示されていないものは複製しない扱いにしています
