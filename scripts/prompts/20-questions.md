## 書くファイル

**`src/data/questions/【章 ID】.ts` だけ**を書いてください。
**他のファイルは絶対に変更しないでください。**

```ts
import type { Question } from '../../types';

export const 【章 ID をキャメルケースにしたもの】: Question[] = [
  {
    id: '【章 ID】-1',
    categoryId: '【章 ID】',
    sectionId: 'lw-2',
    question: '次のイ、ロ、ハの記述のうち、…について正しいものはどれか。\nイ．…\nロ．…\nハ．…',
    choices: ['イ', 'ロ', 'イ、ハ', 'ロ、ハ', 'イ、ロ、ハ'],
    answer: 2,
    explanation: '…',
    level: 2,
  },
];
```

- **`sectionId` は必ず付けること。**解説から教本へ戻る導線と、節ごとの出題に使います
- **`id` は `【章 ID】-1` から連番**
- **`level` は 1（易）〜3（難）。**1 と 3 に寄せず、2 を中心に散らす

## ★ 設問の形（**公開問題で確定済み。推測ではありません**）

```
問 N 次のイ、ロ、ハ、ニの記述のうち、〈テーマ〉について正しいものはどれか。
  イ … ロ … ハ … ニ …
(1) イ、ロ  (2) イ、ハ  (3) ロ、ニ  (4) イ、ハ、ニ  (5) ロ、ハ、ニ
```

| 科目 | 記述の数 | 選択肢の作り |
| --- | --- | --- |
| **法令**（`law-*`） | **イ・ロ・ハ の 3 つ** | 単独・2 つ組・3 つ全部が混ざる |
| **保安管理技術**（`ho-*`） | **イ・ロ・ハ・ニ の 4 つ** | **必ず「2 要素の組 3 つ ＋ 3 要素の組 2 つ」** |
| **学識**（`gk-*` / `gm-*`） | **4 つが基本** | 単独が混じってよい |

### 書き方

- **記述は `question` の中に並べます。**`\nイ．…\nロ．…` のように、
  **全角のピリオド `．`** を使ってください（半角の `.` は `npm run check` が弾きます）
- **`choices` には組合せを入れます。**`'イ、ハ'` のように、**読点は全角の `、`**
- **柱書き（1 行目）は「正しいものはどれか」。**
  **「誤っているものはどれか」は書かないでください。**
  乙種の公開問題 6 冊（延べ 100 問）に**1 問もありません**
- **`answer` は 0〜4 の数値ひとつ。**配列は使いません

### `npm run check` が見ているもの

- **科目ごとの記述の数**（法令は 3、ほかは 4）
- **保安管理技術の選択肢の構成**（2 要素 3 つ ＋ 3 要素 2 つ）
- **柱書きに否定語がないか**（記述の中に「正しくない」があるのは問題ありません）
- **記号の全角・半角**
- **選択肢に重複がないか、存在しない記号を指していないか**
- **正解の位置の偏り**（ならして各 20 %）

## 計算問題

**学識だけに出ます。**しかも多くありません。

| 科目 | R7 の計算問題 |
| --- | --- |
| 学識（化学） | **15 問中 4 問**（密度・圧縮係数・理論空気量・バージェス-ホイーラー） |
| 学識（機械） | **15 問中 1 問**（理想気体の状態変化） |
| 法令・保安管理技術 | **0 問** |

**計算問題は `choices` が数値 5 つ**になります。この形だけは組合せ選択ではありません。

```ts
choices: ['0.12 kg/m³', '0.24 kg/m³', '0.48 kg/m³', '0.96 kg/m³', '1.92 kg/m³'],
```

- **書く数は、章の問題数の 4 分の 1 まで**にしてください。詰め込みすぎです
- **★ 電卓は四則計算のみ**（開平計算は可、対数・指数・三角関数は不可）。
  **対数や指数の値を出させる問題を作らないでください**
- **誤答は「ありがちな間違え方」で作る。**
  ゲージ圧力のまま計算した値、セルシウス温度のまま入れた値、桁を 1 つ間違えた値。
  **ただの倍数を並べないこと**

## 守ること

### 問題文

- **教本を読んでいなくても、問題文だけで何を問われているか分かること**
- **「本文で述べた」「この節の」のような参照を書かないこと。**
  模試では節の順に出ません（`npm run check` が弾きます）
- **ガスの種類・圧力・数量の条件を、記述の中に必ず書くこと。**
  **この試験は、その条件で答えが変わります**

### 記述（イ・ロ・ハ・ニ）

- **1 つの記述で 1 つのことだけを言う。**2 つ言うと、正誤が定まりません
- **正しい記述と誤りの記述を、同じ密度で書く。**
  正しいものだけが長いと、読まずに「長いほうを選ぶ」で当てられます
- **「必ず」「すべて」「いずれも」を誤り専用にしないこと。**
  **正しい記述にも言い切りを入れてください**（法令には「常に」が本当に正しい規定があります。
  たとえば充塡容器・残ガス容器は**常に**温度 40 度以下）
- **誤りの作り方は、次の型から選ぶ**

| 型 | 例 |
| --- | --- |
| **数値を変える** | 保安距離、再検査の期間、温度の上限、貯蔵能力の境目 |
| **適用範囲を広げる／狭める** | 「すべての貯槽に」→ 本当は貯蔵能力が一定以上のものだけ |
| **主体を入れ替える** | 保安検査（知事）と定期自主検査（事業者） |
| **許可と届出を入れ替える** | 第一種製造者は許可、第二種製造者は届出 |
| **ガスの種類を入れ替える** | 可燃性ガスの定めを不活性ガスに当てはめる |
| **順序を入れ替える** | 置換の手順、完成検査と使用開始 |

### 解説

- **正解の理由だけでなく、誤りの記述が「なぜ誤りか」を 1 つずつ書くこと**
- **条番号を書くなら、条文に当たって確かめること**
- **数値は台帳の値をそのまま使うこと**
- **「〜と覚えましょう」で終わらせない。**理由を書く

### 章をまたいだ重複

- **保安管理技術と学識はテーマが重なります**（燃焼・爆発、材料、圧縮機、ポンプ、計測機器）。
  **同じ問題を両方に書かないでください**
- **同じ用語を、科目によって違う説明にしないこと**
- `npm run check` が、章をまたいだ似た問題を検出して警告します

## ★ 数値を書くときの決まり

1. **`docs/primary-numbers.md` に載っている値だけを使う**
2. **台帳に無い数値が必要になったら、その問題を書かずに報告する**
3. **誤答側の数値も、台帳の値から作る**（「ありそうな別の規定の値」が、いちばん効く誤答です）
4. **条文の要件を引用するなら、要件を全部並べる。**
   **1 つ落とすと、誤答のつもりが正答になります**

**★ この型が、系譜でいちばん重い誤りです。**
「誤答が実は正しい」は、ただし書きや例外条件を落としたときに起きます。

## バックスラッシュの落とし穴

問題文も TypeScript の文字列です。

| 書きたいもの | ファイルに書く形 |
| --- | --- |
| 改行 | `\n`（**文字列の中なのでこれでよい**） |
| 数式の `\frac` | **`\\frac`** |
| バックティック | バックスラッシュ ＋ バックティック |

**★ bash のヒアドキュメントを使わないでください。**バックスラッシュを落とします。

---

## やってはいけないこと

1. **公開問題の原文を写さないこと。**KHK のページに著作権表示があります。
   **設問の形を真似るのはかまいませんが、文面を写してはいけません。すべて書き下ろすこと**
2. **指定されたファイル以外を変更しないこと**
3. **`npm run check` を実行しないこと**（並行実行でキャッシュが衝突します）
4. **「事実に自信がない箇所はありません」と報告しないこと**

---

## 報告

1. **書いた問題の数**と、**節ごとの内訳**
2. **計算問題を何問入れたか**
3. **台帳に無くて書けなかった数値**
4. **★ 自信がない箇所**（正解が 1 つに定まるか怪しいもの、条番号、適用範囲）
5. **他の章と重なりそうな問題**

**4 が空の報告は受け付けません。**必ず 1 つ以上挙げてください。
