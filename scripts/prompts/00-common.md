## 何を作っているか

**危険物取扱者試験 甲種**（一般財団法人消防試験研究センターが実施）**の学習アプリの教本**です。
問題集アプリではありません。**「通読できる教本」が最優先の要件**で、演習機能より教本の質を優先します。

まず `CLAUDE.md` を読んでください。ここに書いていない方針はすべてそこにあります。

**出題範囲は `docs/syllabus.md` にあります。**この試験には公表されたシラバスが無いので、
消防法・政令・規則と、消防試験研究センターの公開問題 45 問から自前で起こしたものです。
**あなたの担当する節がどの項目に当たるかは、章のプロンプトに書いてあります。**

**節割りは `docs/section-plan.md` で確定しています。**節を足したり削ったりしないでください。

## この試験に固有の 4 つの要求

### 1. 数字をごまかさない

**この試験は数字そのものを問います。**指定数量、保安距離、保有空地の幅、タンクの容量、危険等級。

**`docs/primary-numbers.md` を必ず開いてください。**一次資料と突き合わせた数値の台帳です。

- **A 節（法令から取った値）は断定して書いてよい。**「10 m 以上である」と書けます
- **B 節には物性値の数値がありません。**
  個別物質の引火点・発火点・沸点・比重の**数値は書かないでください。**
  代わりに**「向き」**で書きます（「水より重い」「無臭」「常温で引火の危険がある」）。
  **この試験の性消 20 問には、数値を問う問題が 1 問もありませんでした**
- **「およそ」「〜程度」で逃げるのも禁止です。**台帳の値をそのまま使うか、書かないか

**台帳に無い数字が要ると判断したら、本文に書かずに報告へ挙げてください。**

### 2. 法令の条文は、要件を全部並べる

**系譜で繰り返し出ている誤りが「条文の要件の書き落とし」です。**
「A または B」を「A」とだけ書く、「ただし〜を除く」を落とす、といった型です。

- 条文を要約するときは、**「または」「かつ」「〜を除く」を落とさない**こと
- 例：**特殊引火物の定義は「発火点 100 ℃以下」または「引火点 −20 ℃以下かつ沸点 40 ℃以下」**。
  **「かつ」でつなぐと誤りになります**
- 条番号を書くなら、`docs/primary-numbers.md` に載っているものだけにしてください。
  **記憶で条番号を書かないこと**（このリポジトリでも実際に間違えました）

### 3. 科目の線引きを守る

**燃焼と消火の理論は、物化（`sf-` / `ss-`）と性消（`pg-` と各類）のどちらでも扱います。**
範囲の重複ではなく、**問われ方が違う**だけです。

| | 物化で扱う | 性消で扱う |
| --- | --- | --- |
| 燃焼 | 燃焼とは何か（定義・3 要素・形式） | この物質はなぜ燃えやすいか |
| 消火 | 消火の 4 要素、消火剤の原理 | **この類の火災にこれが使えるか** |

**同じ用語を章によって違う説明にしないでください。**用語の定義は物化の側に合わせます。

### 4. ★ 類を取り違えない

**甲種でいちばん重い誤りです。**6 類ぶんの物質名・性質・消火方法が入り混じります。

- **物質名を書くときは、`docs/primary-numbers.md` の A-1（別表第一の品名）で確かめる**
- **「〜のものがある」を類の全体へ広げない。**
  「第 3 類は水に触れると発火する」は誤りです（黄りんは自然発火性だけ）
- **消火方法は類ごとに違います。**`docs/primary-numbers.md` の A-14（政令別表第五）を見ること。
  **同じ類でも、第 1 類の無機過酸化物・第 2 類の鉄粉等・第 3 類の禁水性物品は結論が割れます**

## 節の骨格

1 つの節は、次の形で書いてください。**この書式は `src/lib/digest.ts` が
直前チェックシートへ機械的に抜き出します。崩すと拾われません。**

```
# ざっくり言うと
（日常語で「何の話か」。3〜5 行）

（本論。見出し・表・図）

> **試験のポイント** …（暗記すべき事項）
> **よくある勘違い** …（先回りして潰す誤解）

# この節のまとめ
- （箇条書き 5〜6 個）

（一問一答ブロック）
```

- **`# ざっくり言うと` と `# この節のまとめ` は必須です。**文言を変えないこと
- **`> **試験のポイント**` は各節に 1 つ以上。**行頭の `> ` と `**…**` の形を崩さないこと
- **`> **よくある勘違い**` は、本当に勘違いであるものだけに使ってください。**
  **「◯◯だと思われがちですが、実は△△です」**の形になっているか確かめること。
  **この読者にとっての「勘違い」は、たいてい乙 4 の知識の一般化です**

## 一問一答は厚めに

**本番は 45 問を 150 分（1 問あたり 3 分 20 秒）で解く試験です。**
時間には余裕があるので、**速さより「覚えているか」で決まります。**

**指定数量・危険等級・混載の可否・消火の適応・注意事項の文言は、一問一答向きの題材です。**
各節の末尾に、次の形で **5 問以上**（できれば 6〜8 問）置いてください。

- 1 行 1 問。`問い :: 答え` の形
- 問いも答えも 1 行に収める（改行しない）
- 答えは、その場で声に出して言える長さにする
- **問いの中に `::` を使わない**

## 記法（Markdown サブセット）

使えるのは次だけです。**それ以外の Markdown 記法は動きません。**

- 見出し `#`（節内の大見出し）/ `##` / `###`
- 箇条書き `- ` と `1. `（2 スペースで 1 段ネスト）
- 表（`| a | b |` と区切り行 `| --- | --- |`）
- 引用 `> `（試験のポイント・よくある勘違いに使う）
- 強調 `**…**` / コード表記 `` `…` ``
- アプリ内リンク `[文字](textbook/節id)`。**外部 URL は書けません**
- 水平線 `---`
- 行内数式 `$…$`。**甲種では使う場面があります**（気体の法則、物質量）。
  ただし四則演算で書ける式に `$` を使わないこと

**表を厚く使ってください。**この試験は「値の対応表」が知識の本体です。
指定数量の表、危険等級の表、混載の表、消火設備の適応表は、
**文章より表のほうが読者の役に立ちます。**

### 図

```` ```diagram:種類 ```` で図を書けます。使える種類は
`flow` `stack` `tree` `matrix` `cycle` `seq` `bits` `compare` の 8 つです。

- `キー: 値` の行は指示子（`title` `top` `bottom` `x` `y` `note` `actors` `caption`）
- それ以外の行が要素。`ラベル :: 補足` で**補足**を付けられる
- `tree` はインデント 2 スペースで 1 段のネスト
- `stack` は**先頭が最も幅広い**
- `seq` は `A -> B :: 内容` の形で書く。**矢印が無いと `::` の右が黙って消えます**
- **図の中では `**強調**` が効きません。**アスタリスクがそのまま画面に出ます
- **図の題に「N つ」と書いたら、要素の数を N 個に合わせてください。**検査が数えます

#### `compare` の書き方（**系譜で 4 回壊しています**）

`compare` は **「1 行 1 セル、偶数行が左・奇数行が右」**です。
**`::` は左右の区切りではありません。**

正しい書き方：

```
title: 運搬と移送
actors: 運搬 | 移送
容器に入れて車両で運ぶ
移動タンク貯蔵所で運ぶ
指定数量未満でも基準がかかる
指定数量にかかわらず基準がかかる
危険物取扱者の同乗は要らない
危険物取扱者が乗車する
```

**やってはいけない書き方**（意味が壊れます）：

```
容器に入れて車両で運ぶ :: 移動タンク貯蔵所で運ぶ
```

## バックスラッシュの落とし穴（重要）

本文は **TypeScript のテンプレートリテラル**（バッククォートで囲んだ文字列）の中に書きます。

| 書きたいもの | ファイルに書く形 |
| --- | --- |
| `\n` を文字として出す | `\\n` |
| バッククォート | バックスラッシュ + バッククォート |
| `$` + `{` | バックスラッシュ + `$` + `{` |

**bash のヒアドキュメント（`cat > file <<'EOF'`）は使わないでください。**
バックスラッシュが落ちます。

### いちばん壊れるのは ``` のフェンスです

` ```diagram:flow ` と ` ```quiz ` のフェンスを**生のバッククォート 3 つ**で書くと、
そこで本文の文字列が終わったことになり、続きが TypeScript のコードとして読まれます。
**姉妹アプリで実際にファイルごと壊れました。**

**ファイルに書く形はこうです**（バッククォートの前に必ずバックスラッシュ）。

```
\`\`\`diagram:flow
title: ...
\`\`\`
```

つまり **6 文字**で 1 つのフェンスになります。**閉じる側も同じです。忘れやすいのは閉じる側です。**

## 名指しで釘を刺しておくこと

**系譜では、名指しした箇所は全章で正しく書けていました。**下の 10 個は必ず守ってください。

1. **特殊引火物の定義は「または」**。「発火点 100 ℃以下**かつ**引火点 −20 ℃以下」は誤り
2. **気体は危険物ではない。**プロパン・水素・アセチレンは高圧ガス保安法の側
3. **保安講習は「3 年に 1 回」ではない。**起点が「受講日以後における最初の 4 月 1 日」
4. **仮貯蔵・仮取扱いは「許可」ではなく「承認」**。しかも**消防長または消防署長**。
   **仮使用は「承認」だが相手は市町村長等。**この 2 つを混ぜないこと
5. **予防規程は「届出」ではなく「認可」。**定めるのは**所有者等**であって危険物取扱者ではない
6. **水は棒状でも霧状でも第 4 類に効かない。**効くのは**霧状の強化液**。**棒状の強化液は効きません**
7. **乾燥砂・膨張ひる石・膨張真珠岩だけが全区分に適応する。**消火器はどれも適応しない区分がある
8. **第 1 類と第 6 類は不燃性。**それ自体は燃えない
9. **第 5 類に窒息消火は効かない。**自分の中に酸素を持っているから
10. **第 6 類の指定数量は 300 kg。**液体なのに重量で数える（第 4 類だけが L）
