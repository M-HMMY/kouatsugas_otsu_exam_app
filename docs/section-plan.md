# 章立てと節割り

**CLAUDE.md の「次にやること」の 4 番目。**
[syllabus.md](syllabus.md) §6 で挙げた**「いまの章立てと実際の出題が合っていない 3 点」**を、
ここで決着させます。

**根拠は令和 7 年度の公開問題 1 年分だけです**（[public-questions.md](public-questions.md)）。
**n = 1 なので、問題数の配分は「R7 ではこうだった」以上のことを言っていません。**

---

## 1. ★ 決めたこと — 保安管理技術の分野を 1 つに統合する

**`FieldId` を 6 つから 5 つに減らします。**

```
旧: intro / law / hoan-kagaku / gaku-kagaku / hoan-kikai / gaku-kikai   （6 つ）
新: intro / law / hoan        / gaku-kagaku / gaku-kikai                （5 つ）
```

### なぜ

**令和 7 年度の保安管理技術は、乙種化学と乙種機械で 15 問中 14 問が同じ問題でした。**
正解番号の数列も 15 問すべて一致しています。違うのは問 7 だけです。

| | 化学 | 機械 |
| --- | --- | --- |
| 問 7 のテーマ | 流動・伝熱・分離 | ポンプ |

**分野を 2 つに分けたままだと、同じ本文を 2 回書くことになります。**
`Category.field` は 1 つしか持てないので、章を共有できません。
**2 本書けば、2 本とも直さないと片方だけ古くなります。**姉妹アプリで何度も起きた型です。

### 統合しても壊れないこと

- **`scripts/check.ts` の「章の `questions` の合計＝科目の公表値」検査**
  … `hoan` は 15 問。**30 問にはなりません。**CLAUDE.md が禁じているのは
  「保安管理技術と学識をまとめて 30 問にすること」で、これはそれではありません
- **模試の構成比** … 乙種化学は `law` 20 ＋ `hoan` 15 ＋ `gaku-kagaku` 15 ＝ 50 問。
  乙種機械は `gaku-kikai` に差し替えるだけ。**本番どおりです**
- **科目免除の 2 形式** … 「法令だけ」は `law`、
  「保安管理技術＋学識」は `hoan` ＋ どちらかの学識。**そのまま組めます**

### 問 7 の枠はどうするか

**1 つの章「流れ・伝熱と流体機械」にまとめ、両方を書きます。**

区分ごとに章を分けると、`questions` の合計が 15 を超えるか、
どちらかを 0 問にすることになって配分が嘘になります。
**そして、どちらの話も相手の区分で無駄になりません。**

- **ポンプ**は、乙種機械の**学識**でも 1 問出ます（R7 問 14）
- **流動・伝熱**は、乙種機械の**学識**でも 2 問出ます（R7 問 6・問 7）

**章の扉に「本番の問 7 は、化学なら流動・伝熱・分離、機械ならポンプが出ます」と書けば足ります。**

### 戻し方

**もし令和 6 年度以前の問題が手に入って、区分の差がもっと大きいと分かったら、戻せます。**
触るのは 3 ファイルだけです。

| ファイル | 何をした |
| --- | --- |
| `src/types.ts` | `FieldId` から `hoan-kagaku` / `hoan-kikai` を外し、`hoan` を入れた |
| `src/data/categories.ts` | `FIELDS` を 5 つに。保安管理技術の章の `field` を `hoan` に |
| `src/pages/Mock.tsx` | `PRESETS` の `fields` を差し替えた |

## 2. ★ 決めたこと — 学識（化学）の「ガスの製造プロセス」を外す

**`gk-process`（ガスの製造プロセス）は、R7 の学識（化学）に該当問題が 1 問もありませんでした。**
代わりに**燃焼・爆発が 15 問中 6 問**（4 割）を占めています。

**いちばん出るところに章が無く、出ないところに 5 問ぶんの章がある**という状態でした。
**外して、燃焼・爆発とガスの性質に置き換えます。**

## 3. ★ 決めたこと — `questions` を R7 の実測から割り直す

**いまの `questions` は 5 問ずつの均等割りで、根拠がありません。**
R7 の 1 問ずつをどの章に置くかを決めて、その数を書きます。

**★ これは「R7 ではこうだった」という数字です。**毎年この配分だとは言っていません。
**模試の構成比がおかしくならない程度の目安**として使います。

## 5. 節の割り方

### 節 ID の形

**`scripts/check.ts` は節 ID を `[a-z]+-?\d+` で見ます。**この形から外れると、
本文リンクの検査（`scripts/prompts/00-common.md` の一覧との突き合わせ）が働きません。

| 科目 | 接頭辞 | 例 |
| --- | --- | --- |
| 入門編 | `i-` | `i-1` 〜 `i-4` |
| 法令 | `lw-` | `lw-1` 〜 |
| 保安管理技術 | `ho-` | `ho-1` 〜 |
| 学識（化学） | `gk-` | `gk-1` 〜 |
| 学識（機械） | `gm-` | `gm-1` 〜 |

**科目ごとの通し番号にします。**章ごとに振り直すと、章を入れ替えたときに全部ずれます。

**★ 章 ID と節 ID の接頭辞が似ているので注意。**
章 ID は `ho-burn` のように語、節 ID は `ho-3` のように数です。

### 1 節の大きさ

**1 節 = 10〜15 分。**姉妹アプリと同じです。
問題 1 問ぶんのテーマに対して**節 2〜3 本**が目安になります。

| 科目 | 本番の問題数 | 節の見積り |
| --- | --- | --- |
| 入門編 | 0 | 4 |
| 法令 | 20 | **40〜45** |
| 保安管理技術 | 15 | **30〜35** |
| 学識（化学） | 15 | **30〜35** |
| 学識（機械） | 15 | **30〜35** |
| | | **合計 135〜155 節** |

**学識は化学と機械の両方を書くので、節の総数は本番 50 問ぶんより多くなります。**
**法令と保安管理技術は 1 本で済みます**（両区分共通なので）。
